# 设计：移除文字内容分享

## Context

当前内容分享由详情或成稿页进入分享预览，服务端创建文字快照与 token，接收页根据 token 读取内容。该流程与普通欢迎页转发独立。意见反馈目前与分享共用客户端和服务端模块。

## Goals / Non-Goals

- 完整移除可供他人读取用户文字的客户端和业务 API。
- 保留普通小程序转发、意见反馈和原有记录、整理、复制、导出流程。
- 页面仅调整失效入口与操作文案，不增加「仅本人可见」等解释。
- 不部署、不改远端集合、不迁移或清理正式数据，不承诺审核通过。

## Decisions

- 删除三个内容分享页面及其专用客户端模块、海报生成与素材；从 app/sitemap 和页面入口移除注册。
- 意见反馈独立为 feedback 客户端与服务端模块。只接收 bug、idea、other 三种新反馈；历史分享举报记录仍可在本人反馈列表读取，现有字段兼容。
- 协议仅保留 snapshot.pull、snapshot.push、inspiration.delete、photo.delete、feedback.create、feedback.listMine。旧 share.* 和 feedback.reportShare 返回 INVALID_ACTION，不读取或创建文字快照。
- 删除分享密钥、内容审核、小程序码的 API 入口与部署配置；历史分享保留期清理单独保留，不暴露内容读取接口。
- 删除直接发送 TXT 文件的按钮及 wx.shareFileMessage 调用，保留复制和生成 TXT 临时文件，不新增文件发送或图片保存能力。
- 同步移除不再使用的分享跳转意图与字段。现有账户记录、保存确认、反馈幂等、事务配额和账户隔离约束继续生效。

## Risks / Trade-offs

配套部署后旧版本客户端的内容分享动作失败，旧链接无法再读取；本次仅修改本地发布输入，远端仍由已部署版本决定。已发送的文字、文件和海报无法远程收回。

## Validation

验证旧分享动作均被拒绝、客户端无内容分享页面及入口、普通欢迎页转发不含用户文字、反馈仍可提交与读取、记录和导出回归通过。运行 npm test、npm run check、OpenSpec 严格校验及可用的原生编译；真机与重新审核分别留待对应验收。
