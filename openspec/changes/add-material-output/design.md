# Design

## Context

沿用 services/content-output 的模板与现有 store 保存接口，新增纯函数选材服务和独立页面，避免改变单条留档的含历史语义。

## Decisions

正文与每条有效补充各是一段素材，默认全不选。保留选择顺序，取消后再选排在末尾。每次最多 40 段、20 条来源、合计 12000 字（含段间换行），限制只作用于本次整理，不限制记录量。

生成时从当前可信 store 重新读取选中素材，逐段比对内容和归属；删除、收起或内容变化则停止生成，保留当前稿件，可主动刷新素材重新选择。历史、照片、标签和隐藏补充不作为输出素材。

另存使用既有 user 来源记录结构，不新增数据库字段；来源不删除或收起。保存成功后同一未改稿件不重复另存，保存失败保留全文。复制和保存只响应当前页面、账户及稿件的结果。

## Risks

未保存草稿离开页面会清除，界面明确提示。云权限、微信剪贴板及原生输入仍须独立验收。新增私人页面统一禁止索引，不把 sitemap 当访问控制。
