# 跨灵感手动选材整理

## Why

优化方案 §10 P2 已列出跨灵感手动选材。当前单条整理不能组合不同记录，AI 汇总又依赖尚未启用的模型；用户要求继续完成剩余开发。

## What Changes

- 从灵感列表进入手动选材，分别勾选多条记录的正文或有效补充，按选择顺序组合。
- 使用已有五类模板，只保留选定文字及结构，不新增事实，不调用 AI。
- 支持编辑、复制、另存新灵感；重新生成前保护编辑，来源变化时拒绝静默替换。
- 新增页面清理账户切换时的私有内容，并补齐现有 AI、照片查看页的索引排除。

## Non-goals

不自动合并/修改来源，不新增云集合、分享协议或后台任务，不部署或启用 AI。不处理会员、支付、通用撤回和长文协作。选材草稿仅会话内存在，不承诺离开后保留。

## Acceptance

选择、隐私边界、来源失效、上限、保护编辑、复制失败、另存失败、账户切换有测试；规范和设计同步。真实剪贴板、云写入和真机另验。新增代码留工作区，不自动提交或推送。
