# 灵感归档设计

## Decisions

- 在灵感上新增 archivedAt:number|null，旧缺失按 null。领域提供 markArchived(item,{now})、unarchive(item)、isArchived(item)，不改变 updatedAt、历史或内容；重复归档保留原时间。已合并来源先恢复独立再归档。
- 我的固定入口打开 pages/archived/index；归档按归档时间倒序，搜索当前正文、有效补充和标签。普通读取保留全量快照，默认列表与选材排除归档。
- snapshot.push 不增加动作。省略 archivedAt 时继承已有值，新记录缺省 null；客户端发送、确认落内存与回读比较使用相同有效记录。服务端以版本 CAS 防止覆盖其他设备更新。
- 归档/取消归档只能改变 archivedAt；归档中不许修改其他字段或改写归档时间。拒绝取消归档同时编辑、归档与已合并状态叠加、新建即归档。明确返回 INSPIRATION_ARCHIVED / INVALID_PAYLOAD。
- photo.delete 在登记新清理任务前检查归档；已登记任务继续收敛，整条删除沿用原有闭环。系统删除目标后解除来源 mergedInto 引用保留其他字段。
- 详情 pending、照片处理中、未保存输入或未知保存时阻止归档。归档目标对象保存在当前页面内存供重试，不重新生成时间；云端确认才切换页面状态。
- output 按当前记录强制只读 exportOnly，普通路由同样生效；不恢复、覆盖或删除普通稿件会话草稿。来源中途归档保留现稿供复制，停止生成和另存。

## Rollout

不新增资源或执行数据迁移。经独立部署授权后，先部署服务端兼容与冻结规则，再发布客户端；旧版界面仍可能显示归档记录。前端回滚保留 archivedAt，服务端兼容规则不能回退为静默清除归档的旧实现。正式保存、多账户、照片清理与真机交互另行验收。
