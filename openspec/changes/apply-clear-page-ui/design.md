# Design: 清晰轻页

## Context

采用已批准的 `design-demos/2026-10-28/dir-1.html` 作为组件尺寸、布局位置和交互呈现的基准，不得用旧页面布局代替已选示例。已有云确认、连续记录、账户隔离及归档规则继续有效；平台原生导航按微信规范保留；首页照片及标签已按后续明确要求接入既有保存和私有读取能力。

## Decisions

- 模式为 Operate。白色内容面，主色 `#2d438c`，正文 `#202b40`，辅助 `#5e697f`，浅底 `#eff2f9`，分隔 `#e7eaf0`；主要间距22px，窄屏按17px左右收缩。
- 正文使用系统中文无衬线，列表16px、详情/记录17px、辅助不少于12px；触摸区至少44px。以留白与细线区分层级，不把清单切成浮动卡片。
- 保留现有事件、`wx:if` 守卫、输入上限和禁用条件；阶段保持直接可点，时间保留 `YYYY-MM-DD HH:mm:ss`。
- 保存仅在服务端确认后成功；未知结果、账户切换、页面版本和来源只读规则不因样式重排而改变。
- 2026-10-28一致性修正：主页面品牌行25px、标题行67px；主按钮48px、图标按钮44px、搜索45px、开关42×25px、记录输入194px。筛选按内容占宽，不等分拉伸。记录保存固定底部，详情整理与补充固定底部；补充初始收起，点击展开，已有草稿及未知结果不隐藏。
- 以原型和原生页面的成对运行测量及截图验收上述尺寸，不以测试通过或整体配色相近代替一致性检查。平台原生导航、完整到秒时间、既有待办范围与日期快捷选项、连续记录保护继续保留。
- 照片先确认当前源码和可复现失败，再改最小实现；不生成公开文件URL、不持久化照片草稿、不扩大账户路径范围。
- 若根因涉及云端开关、函数部署或共享存储权限，将精确条件与验证证据列出，完成本地修复后再按适用授权处理。

## Rollback

按文件差异恢复本次页面样式和照片修复即可，不涉及数据迁移。保留三方向原型与已选方向记录，不覆盖此前未提交内容。


## 首页照片与标签

标签经现有organize校验，与正文待办一次保存；未知回执复用完整快照，编辑标签后使旧操作失效。添加照片先选择来源，再确认保存记录，随后使用既有照片服务并显示首页缩略图。不新增照片草稿、云API或数据库字段。私有路径不放入sessionDrafts；隐藏、账户变化和新记录使旧读取失效。
