# 仅以云端确认为保存

## Why

当前客户端先把正文、操作队列及照片写入设备持久空间，再尝试同步。用户明确选择“不允许落盘：联网且云端确认才算保存”。现有“已保存但未备份”的行为与该选择冲突。

## What Changes

- 新的读写会话只从可信云端快照初始化；正文、历史、照片任务、回顾状态及自愿统计不再写入小程序持久存储。
- 保存和删除均在服务端确认后才更新会话内视图并报告成功；失败保留当前输入，不建立离线队列。
- 拍照/选图只使用微信提供的临时路径直接上传，不调用 `wx.saveFile`。云文件上传成功但记录写入失败时，尝试核对与清理孤立文件。
- 开发阶段的旧测试缓存不参与新会话，不扫描、不回放；用户确认没有需要保留的真实数据，因此不开发迁移或恢复流程。

## Scope

本项目小程序的账户初始化、内容写入、照片流程及相应页面。共享正式环境中的其他应用资源不变。

## Non-goals

不启用 AI，不执行正式云函数部署，也不承诺微信系统临时文件和用户主动复制/导出文件绝不落盘。不在小程序启动时清理设备调试缓存；开发者可在验证前按需清理自己的测试环境。

## Acceptance

自动测试证明无持久存储读写、失败不报成功、失败后输入保留、照片不调用保存文件、账户切换不显示旧账户内容。开发者工具与真机再分别验证网络失败及超时后重试。
