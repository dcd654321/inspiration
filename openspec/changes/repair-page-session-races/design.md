## Context
以当前源码为准，AI 汇总补充带 source=ai 与至少两个 sourceIds，领域及服务端上限为 2000；普通用户补充仍为 1000。

## Goals / Non-Goals
目标是修复现有流程在等待、重复操作、页面隐藏、账户更换后的行为。非目标为云端启用、部署、数据迁移、共享配置或发布。

## Decisions
统一页面会话守卫只持有内存中的页面版本、store 引用和 sessionEpoch；任何读取准备和回执均检查当前上下文。分页另外持有列表代次，后续页读取串行且按实体 ID 去重。提交前冻结快照。临时海报渲染每次异步后检查会话，失效仅清理该次文件。服务器对象比较保留数组顺序，忽略对象键顺序。

## Risks / Trade-offs
页面隐藏丢弃分享预览与临时资源，返回重新确认；取消发送和相册权限弹窗的真实平台生命周期仍需真机验收。Node 及隔离工程不证明云端部署版本或真实权限。
