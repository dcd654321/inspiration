## Context

现有账户文档内嵌灵感及补充，snapshot.push 按账户版本及代际 CAS 保存整条记录。归档字段独立于整理阶段，归档后整条只读。

## Goals / Non-Goals

支持灵感与补充各自独立的轻量待办、可选计划日期、统一看板。保留记录入口及云确认保存。首版无自动提醒、循环、优先级、成员或独立任务集合。

## Decisions

- 在来源上内嵌 todo，不复制文字。todo=null 表示普通记录；对象包含 createdAt、completedAt、dueDate。
- 计划日期保存 YYYY-MM-DD，按设备本地日历比较，跨日重新分组。
- 看板汇总完整快照，含归档、并入和历史合并来源；归档和合并来源修改前须恢复。
- 待办元信息不修改文字 updatedAt 或历史。旧客户端省略字段继承原值，显式 null 才清除。
- 待办写入固定原版本、目标和 requestId，结果未知先回读；版本变化且目标未达成时停止旧操作。
- 归档有未办只作继续确认，不增加服务端禁止归档规则；归档后的所有待办属性仍被冻结。

## Risks / Trade-offs

完整快照汇总适用当前账户结构，不新增分页查询或独立索引。真实云部署、微信编译与真机分别验收，回滚保留 todo 字段。
