## Context
复核依据为 docs/UI-INTERACTION-REVIEW-20261001.md 与开发者工具实际渲染、合成延迟/失败注入。当前仅云端确认保存，不使用本机持久草稿。

## Decisions
1. 保存时冻结编辑器，并以输入事件防护作为第二层保护；成功状态按当前正文与确认快照逐字比较。
2. 提示未另存内容离开后不保留；仅使用平台支持的返回提醒，不承诺拦截系统手势或退出。另存成功后编辑相同稿件无提醒，重新编辑后恢复提醒。
3. 列表按 store 引用、sessionEpoch、cacheScope 核对当前身份。只在三者未变化且仍可信时保留记录。已可信 store 刷新失败保留列表；重新认证先清空。
4. 多素材页面维护独立的模板与材料行样式，共用稿件编辑器字阶。选择标记包括可见文字/符号，非仅颜色。
5. 弹层采用受可用视口约束的纵向布局，内容滚动，操作区和关闭按钮不可被内容挤走；底留白为基础间距与安全区之和。

## Risks / Trade-offs
冻结输入短暂限制连续编辑，但消除提交快照与新输入歧义。返回提醒依赖平台支持，辅以常驻说明。身份未确认时不保留可见旧列表。键盘、读屏、实际服务仍需独立真机/云端验收。

## Validation
对延迟输入、重复另存、失败重试、迟到回调、确认后再编辑、同会话刷新失败与身份切换增加行为断言；开发者工具复核材料样式、安全区、焦点和长留档操作。分别报告本地测试、模拟器、真机和真实服务。
