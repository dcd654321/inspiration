# Change: 修复 UI 与交互复核问题

## Why
2026-10-01 当前实现复核发现保存期间输入丢失或被误标已另存、多素材样式失配、底部安全区不足、离开稿件提示缺失，以及同账户刷新失败丢失阅读上下文。

## What Changes
- 补充与另存确认期间冻结编辑器，保护提交快照和迟到响应。
- 单条及多素材稿件提供未另存提示和平台支持的返回提醒。
- 修复多素材选项、材料行、底部栏与共用弹层；统一关键字号、表单边界和点击区。
- 继续补充请求原生焦点；同一可信会话读取失败保留列表，身份变化立即清空。
- 另存区分结果未知与明确拒绝，并重用同一待确认实体。

## Impact
涉及 detail、output、material-output、list、photo-viewer 页面及 app.wxss、回归测试和设计/覆盖文档。用户已授权实施这九项修复。不改变数据结构、云配置、AI开关、持久化、删除协议或用户已确认的入口删减，不提交、部署或发布。
