# Change: 修复详情照片展示与标签状态

## Why

详情的照片区排在全部补充和标签之后，上传后缺少明显的查看位置；图片组件加载失败时没有失败反馈。标签输入只更新表单，摘要仍显示旧值，照片上传后的详情重读还会覆盖正在编辑的标签。入口「修改标记」与字段「标签」的措辞也不一致。

## What Changes

- 已关联照片在正文动作下方以单行横向缩略图展示，点击查看大图；读取或图片渲染失败均保留照片占位并给出重试。
- 标签与阶段的编辑摘要随输入更新，明确提示尚未保存；同一页面会话重读保留正在编辑的值，确认保存后显示记录里的值。
- 编辑入口、字段标题和保存按钮统一使用「标签与阶段」，列表补充照片数量提示。

## Impact

- 涉及详情、灵感列表、私有照片读取、页面回归测试与设计文档。
- 属于现有展示和编辑行为修复，不改变数据字段、上传协议、身份、存储规则或共享范围，不部署云函数、不操作真实账户记录。
- 验收：已有照片可找到并预览；失败可重试；输入标签不再同时显示未加标签；照片重读不覆盖标签草稿；未确认保存不冒充成功。
