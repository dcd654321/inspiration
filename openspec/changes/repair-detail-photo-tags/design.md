## Context

详情已有照片下载器和独立私有预览页，已有标签与阶段保存方法。修复复用这些能力。照片读取仍绑定页面版本、可信账户会话和 store。

## Decisions

- 照片区移至正文轻量动作下方，缩略图横向排列，一行高度不随照片数量增加。无照片时仅在照片服务开放的会话中显示添加入口；服务关闭时已有照片仍可查看。
- 列表只显示照片数量，不下载照片或建立公开链接。
- 展开的标签表单显示正在编辑的摘要和「尚未保存」提示。取消或收起恢复展开前的已保存值；上传后的普通重读保留标签草稿。页面账户变化或明确 resetDraft 则恢复新会话的记录值。
- 缩略图渲染失败使用照片 ID 和当次 src 校验事件，旧图片的事件不覆盖重新读取的结果。读取身份条件不满足时不下载，保留失败占位；会话失效仍丢弃结果。

## Risks / Trade-offs

横向缩略图使照片在正文后可见，同时限制其纵向占用。相机、相册与真机图片权限仍需独立验收；合成数据和 Node 测试不代表真实上传或云存储规则通过。
