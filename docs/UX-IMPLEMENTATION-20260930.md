## 1. 实施清单（按 DEV 任务）

### DEV01 记录页（UX01 / UX07）· `pages/capture/*`、`services/cloud-only-store.js`

- 保存状态拆成五种：可编辑（非空显示「尚未保存，退出后可能丢失。」）、保存中（按钮「正在记下…」+「正在保存，请稍候。」）、**结果未知**（「尚未确认保存」+ 重试保存 / 复制内容）、**确认被拒绝**（「未能保存」+ 按已知回执说明原因）、成功（「已记下」+ 本次内容两行摘录 + 继续补充 / 再记一条）。
- 结果未知与确定拒绝的分界：`NETWORK` / `INTERNAL`（含异常）一律按「结果未知」，不宣布失败；其他明确错误码按「确认被拒绝」，原因取自 `cloud-only-store` 透传的服务端 `message`（本次新增透传），没有回执时不编造。
- 重试复用同一记录标识（既有幂等机制不变）；「复制内容」只在用户点击后写剪贴板并给常驻小字。
- 输入层 `maxlength="-1"` 完整接收粘贴，超限显示「超出 N 字符，请缩短后保存。」并禁用提交，提交层继续遵守 2000 上限；空输入不放示例行（用户 2026-09-30 决定去掉，引导由占位符承担）。
- 「继续补充」进入详情并定位输入（`?focus=supplement`）；「再记一条」聚焦空输入；离开提示改为「尚未保存的内容会丢失。」，提交中与结果未知时不叠加该提示。

### DEV02 详情页（UX02 / UX05）· `pages/detail/*`、`app.wxss`

- 新顺序：时间 +「更多」→ 原文 → 「整理成稿 / 继续补充」等宽一行 → 紧凑补充输入（64/160px 两档、关闭 `auto-height`）→ 补充时间线 → 一行「阶段 · 标签 + 修改标记」→ 照片 → 汇总来源。
- 低频操作（修改正文 / 复制全文 / 分享文字 / 修改记录 / 删除灵感）收进「更多」面板；补充面板按定稿改名（复制补充 / 修改补充 / 并入正文 / 删除补充；已收起项为「恢复为补充」）。
- 长正文（> 约 6 行）滚离原文后出现 44px 浮动「继续补充」，键盘/聚焦时隐藏；点击定位并聚焦补充输入。
- 删除确认改为共用自定义弹窗：灵感与补充都展示待删摘录（最多 4 行）与时间；正文照定稿。
- 标记表单增加「取消」并恢复进入前的值；保存成功后自动收起（保留）。
- 读取失败（账户/网络）与确认缺失分开：「暂时无法读取灵感 / 重新读取 / 返回灵感列表」与「找不到这条灵感 / 返回灵感列表」；照片失败给「重新加载照片」，不再写「文件可能已被删除」。

### DEV03 列表页（UX03）· `pages/list/*`、`services/discovery.js`

- 默认筛选行只留「全部 / 有补充 / 筛选」；七天内、阶段、已合并进筛选面板，chip 显示「筛选·N」；「清空搜索」只清搜索词，「重置筛选」只清面板条件，无结果态一次清两者（「清空搜索和筛选」）。
- 回顾从大色卡改为第一条记录之后的轻量行「回看一个想法」，展开才显示预览与「继续补充 / 本次先不看」；列表不足两条或不满足默认视图时不占位。
- 真空态判据改为「有效记录 + 已合并记录都为 0 且读取成功」；仅剩已合并时保留入口并给出「查看已合并内容」；列表行：默认阶段不占行、标签最多 2 个 + 「+N」、去掉重复「查看」、整行可点。
- 同账户返回保留查询与滚动位置（以离开时点击的记录为锚点，找不到退回原偏移）；账户变化清空查询、筛选、锚点与旧内容。
- `services/discovery.js` 的 `searchInspirations` 增加可组合的 `recent` 布尔量（旧 `filter` 语义不变），供面板条件叠加。

### DEV04 整理页（UX04）· `pages/output/*`、`pages/material-output/*`

- 进入即有可编辑的自由稿（补充默认全选），摘要「正文 + N 条补充」；工具行「调整内容 / 选择格式 / 更多（文字留档）」；面板改动先暂存、确认（应用选择 / 应用格式）才写回，取消不改动稿件。
- 手工改过稿件后应用新内容/格式先弹替换确认（「替换当前稿件？」「保留编辑 / 替换稿件」），取消保留文字与选择。
- 复制稿件 / 另存为新灵感：2000 字符以内可另存，超限只禁另存并显示差额；同一稿件重复另存不新增（按钮变「已另存」）；留档面板文案与能力保持。
- `pages/output/index.json` 导航标题改为「整理成稿」；跨条选材页统一「整理成稿 / 复制稿件 / 另存为新灵感」与提示文案，先选后出稿的流程与边界不变。

### DEV05 恢复出口（UX05）· `pages/output`、`detail`、`history`、`photo-viewer`

- 四处统一「找不到这条灵感 / 它可能已被删除，可以返回列表查找其他记录。/ 返回灵感列表（tab 路由）」与「暂时无法读取灵感 / 请稍后重试。/ 重新读取」；修改记录空态改为定稿文案 + 「返回这条灵感」。

### DEV06 分享与「我的」（UX08 / UX09）· `pages/share-preview`、`shared`、`my-shares`、`mine`、`feedback`、`welcome`、`ai-workbench`

- 分享预览：同一主按钮按状态替换（「确认内容并准备分享 → 准备中… → 选择微信好友」，后者是真正的 `open-type="share"`）；「制作海报」为次入口，失败后可重试且复用同一份准备结果；修改选择立即使已准备结果失效。
- 分享落地页：失效写「分享已失效，可请分享者重新发送。」且不给重试；网络类失败写「请检查网络后重试。/ 请稍后重试。」并给「重新读取」；两个分支的记录入口统一「记录我的想法」；快照说明更新为定稿。
- 「我的分享」空态：标题 + 说明 + 「查看我的灵感」入口（离线样例只能到达失败态，空态以结构测试与代码覆盖）。
- 「我的」按用途分组：我的分享 / 数据与隐私 / 使用帮助（显示回顾入口 + C71 说明；诊断信息默认关闭、用户主动查看与复制）/ 意见反馈（提交反馈 / 向微信反馈）/ 关于；删除重复的「查看我的灵感」入口。
- 反馈页、欢迎页文案按定稿更新；AI 工作台关闭态改为「暂时无法使用此功能」+「返回灵感列表」，不写开发进度。

### DEV07 视觉归一（UX06 的本地部分）· `app.wxss` 及相关页样式

- `min-height/min-width: max(88rpx, 44px)` 兜底热区（320 宽下 88rpx 只有约 37.5px）；正文/辅助字号以 `max(30rpx,16px)`、`max(26rpx,13px)` 等表达 16/13px 下限。所有 `max()` 前保留 rpx 声明，基础库不支持时自动回退。
- 遮罩、底部面板、确认框、面板动作行、提示条三段式（标题/说明/动作）从详情页提升到 `app.wxss` 共享，列表与整理页复用同一套组件。

## 6. 已知风险与回滚

- **风险（中）**：`max()` 字号/热区下限的表现依赖基础库对 CSS `max()` 的支持——不支持时回退到 rpx 原值、不会放大；支持时 320 宽上的排版会比原先宽松，需要在真机窄屏复核一次观感。
- **风险（中）**：详情页顺序调整后，「复制全文」「修改正文」多一步打开面板；长文用户首次可能注意不到浮动按钮（已在滚离原文后出现，属渐进提示）。
- **风险（低）**：`searchInspirations` 新增参数为向后兼容扩展；`cloud-only-store` 失败结果新增 `message` 附带字段，按 `code` 断言的既有测试不受影响。
- **回滚**：本轮全部为本地未提交改动，且与上一轮未提交的界面改动混在同一工作区。回滚时按本轮修改的文件组执行 `git diff <paths>` 复核后 `git restore <paths>`；**不要把上一轮的未提交改动一起还原**。建议组：capture / detail / list / output+material-output / share-preview+shared+my-shares+mine+feedback+welcome+ai-workbench / app.wxss+各页样式 / services+测试+文档。没有任何云端状态需要回滚。
