## 本地实现

正文及每条补充分别持有可选待办，支持计划完成日、完成、恢复、移除和五秒撤销。记录与补充一次保存文字及待办。看板汇总完整快照，提供全部、待办、已办数量、当前范围搜索、日期分组、长文展开和补充来源定位。启动仍进入记录页。

归档有未办时提示并允许继续。归档事项保留在看板，处理前须取消整条归档。并入正文或收起补充保留原事项；移除待办保留文字，删除来源确认说明待办及已办数量。

新增字段为正文及补充的 `todo: null | { createdAt, completedAt, dueDate }`，日期为本地日历日期字符串。复用既有快照和版本 CAS，不新增集合、索引、云 action 或持久队列。待办操作不修改文字更新时间和历史。

## 手工验收路径

1. 在隔离工程进入待办页，核对数量、逾期/今天/以后/未设日期/归档分组；切换已办并搜索。
2. 勾选单个正文或补充，核对其他事项不变，点击撤销；从补充打开原文并检查定位及收起区展开。
3. 在记录页及详情补充输入中开启待办，选择日期并保存；切页返回检查未保存输入及日期继续保留。
4. 归档带未办的灵感，分别测试返回和继续归档；核对看板保留只读事项，取消归档后再处理。
5. 检查短屏、长文、日期选择、所有按钮 44px 点击区域及加载/错误/无匹配状态。

## 发布与恢复

本轮未提交、推送、部署、发布，也未执行正式云保存、多账户或真机验收。上线先部署兼容的服务端，再发布客户端，分别取得回执。旧客户端省略字段时服务端按正文及补充 ID 继承待办，显式 null 才清除。

恢复客户端版本时保留已保存的 todo 字段和兼容服务端；不迁移、不清空正式账户。仅回退客户端界面不会删除事项。归档恢复规则保持不变。
