## 320px 边界

本机官方 `miniprogram-automator` API、开发者工具 `auto` CLI 参数及随工具提供的 automator Skill / `tools.yaml` 均未提供设备宽度切换入口；本次未取得 320px 真实模拟器截图，未 mock 系统信息或缩放图片代替。

`static-320-layout.json` 使用 390px 实测控件宽度与当前 CSS 做静态上界核对：正文行保守可用宽度 280px，当前跨年日期组合所需不超过约 273px；补充行保守可用宽度 260px，组合所需不超过约 190px。CSS 在空间不足时允许整颗控件换行，日期自身不折字，按钮保留 44px 下限。这仅是静态分析，不能计作 320px 渲染、换行或操作验收。
