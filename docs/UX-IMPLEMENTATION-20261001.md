# 2026-10-01 体验优化实施

授权：用户要求「你来优化吧」。实施审查 R01—R05；保留现有品牌、原文、补充时间线、模板与选材顺序。

## 状态与交互

- 正文和补充修改保存时冻结输入及导航入口，事件处理也拒绝输入。保存回执只作用于同一页面版本、账户会话和 store；隐藏页面后解锁，旧回执不回填。失败保留输入。
- 网络或无确定回执以警告色显示「尚未确认保存」，明确拒绝以错误色显示「未能保存」，冲突说明需重新核对。未知状态原保存按钮变为「重试保存」，旁边提供复制当前输入。确认成功才退出编辑、读取正式结果。同一次修改在会话内复用历史标识及时间；回读已确认相同正文时不重复追加历史。
- 未提交的正文修改、补充修改、新补充就近提示「尚未保存，退出后可能丢失。」；提交中改为「正在保存，请稍候。」。平台返回提醒只辅助，关闭、侧滑和系统回收仍可能丢失会话内容。
- 记录页警告在唯一主按钮前，未知状态主按钮为「重试保存」，复制是次级动作。同一记录重试仍复用标识。
- 选材阶段只选择内容，首次默认自由稿。成稿后五种格式以按钮提供；有手动编辑时显示替换确认，取消保留原格式、稿件和顺序；确认期间内容、选材或页面变化则忽略旧确认。
- 所有字阶使用原 rpx 值并用 `max(rpx, px)` 设置下限。正文输入至少 16px，辅助至少 13px，主要正文至少 18px，操作入口至少 44px。补充输入使用 `--field-line` 作为 1px 边界，装饰线保持原色。
