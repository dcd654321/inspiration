# 灵感拾光簿：本地产品体验优化实施

实施日期：2026-10-07—08，Asia/Shanghai。分支dev，开始基线504b989；用户追加“生成完了就直接修改优化”授权。本地修改尚未提交。完整产品审查与七项设计交付见 [审查报告](PRODUCT-EXPERIENCE-REVIEW-20261007.md)，[视觉设计板](audits/2026-10-07-review/design-board.html)记录两种方向，[原生改版截图](audits/2026-10-07-implementation/README.md)记录实施结果。

## 1. 已完成的价值路径

保留暖纸、靛蓝、原文与补充时间线、连续列表、可编辑稿件和明确保存回执。首页现在表达“记下一闪念，整理成可用稿”，首记成功展示正文摘录与继续补充、整理这条、再记一条。用户能在确认保存后直接整理和复制，减少进入列表、详情与工具菜单的寻找。

启动页首次onReady即进入可写记录页；账户准备继续在后台。保存始终等待当前受信账户与服务器确认。原生复核修正onLoad过早跳转的懒加载注册竞态；失败只提供重新打开，不把账户准备说成页面导航。

单条和多素材成稿都有“保存并预览分享”；明确确认后使用原受信另存，再进入公开范围核对。已确认相同稿件直接预览，不重复建记录；取消、未知保存、来源变化、过期弹窗或页面隐藏不会跳转。分享确认按钮“保存预览”符合平台4字限制。

## 2. 被打断后的继续与错误恢复

四类页面：记录、单条稿、多素材稿、AI预览，保存同一进程内的文字、选择顺序、模板、来源版本及待确认产物。重新确认相同cacheScope与generation后恢复；确认失败期间不展示旧私人内容，账户或代际变化清除。最多12项、30分钟过期；补充草稿最多32项、30分钟，只有最后确认账户的一套内容。无设备持久快照、离线队列、照片草稿或后台自动写入。

来源变化保留文字供复制，阻止沿旧来源生成/保存，重新读取前明确确认替换。未知另存冻结文字和格式，保留复制与重试，同一逻辑记录ID跨页面返回复用；回读确认已有同产物就结束未知状态。已保存稿件进入分享再返回也保留当前手工稿与ID；若已存记录删除或改动，清除旧确认标记并保留可编辑文字，重新保存后才分享。

原生验证中，多素材稿导航到欢迎页再返回，两段选材及逐字编辑稿恢复。NETWORK由隔离store注入，textarea.disabled=true，重试后显示已另存；真实弱网幂等、后台60秒和双账户另行验收。

## 3. 视觉与操作调整

- 首页常驻字段标签、160px输入区、清楚的成功结果卡；首屏说明最终用途和默认私密。
- 详情主任务集中在补充与整理；AI常用入口为文字链接，汇总补充保留在更多，不删除有效能力。
- 成稿正文至少16px、辅助至少13px、主按钮48px、点击热区44px；按钮允许换行。
- 多素材结果默认收起五种格式，提供“返回选材 / 选择格式”；自由稿和复制回到390×844首屏。选材数字保持进入稿件的顺序，空搜索可一键恢复且不丢选择。
- 未知另存说明放在复制/重试前；只读输入区缩为208px，全文仍保留并可复制。来源变化、空稿、忙碌及未知状态的原生禁用和事件守卫一致。
- 分享先展示对方将看到的文字，再展示公开范围；长文字可展开。底部主动作在准备和反馈出现后保持可达；海报和管理为次入口。接收页的开始操作固定在安全区以上。

保留系统字体、原生导航与胶囊。当前证据仅390×844模拟器；320/375/430px、系统字体放大、键盘候选栏、屏幕阅读与iOS/Android安全区待验。

## 4. 分享与接收

默认仅正文，补充主动选择；照片、修改历史、隐藏补充不会加入。改变范围清除已准备状态。品牌封面为1000×800的5:4包内PNG，无私人正文、照片或账户。准备完成仅提示选择微信好友，不报告发送成功。

公共阅读仅初始化配置的受信共享Cloud连接，调用share.get；不等待接收者私人snapshot.pull。仍保留服务端可信上下文、来源校验、内容审核、限流、30天有效期、撤销和源删除校验。守卫绑定页面、sessionEpoch、token、读取版本与SDK连接代次，旧回执不覆盖新页。网络错误可重读；确认失效不无限重试。

成稿另存附合法templateId（free/social/video/work/action）；分享用途只从已确认来源记录复制，不接受请求伪造正文、身份或用途。接收者开始时只消费一次5分钟用途意图，不带作者原文、token或账户；新用户输入为空，有自己的未完成输入则保留。取消用途不改文字；自己的确认首记后进入对应可填写结构。旧分享或自由稿走通用入口。

真实share.create/get、微信卡片发送、双账户接收、撤销与扫码尚未验证。当前客户端及服务端源码已同步云函数副本，远端未部署；用途承接在部署前可能只显示通用路径。AI来源从正文并入及手工另存传递仍不完整，列为后续协议任务，不能声称已满足全部AI标识要求。

## 6. 验证与验收

本地最终结果在VERIFICATION与原生证据索引登记。检查项：完整测试、结构检查、OpenSpec strict、三个云函数共享副本一致、15个WXML和16个WXSS原生编译。测试覆盖账户、代际、来源变化、未知回执、稳定产物、分享取消/返回和用途非法/过期。所有原生截图逐张检查，合成AI与分享明确标记F。

最终结果：516/516测试、288项结构检查、13/13严格规范校验；39份云函数共享源码核对一致；15份WXML、16份WXSS原生编译通过。改版19张截图已逐张查看，环境和操作在[证据索引](audits/2026-10-07-implementation/README.md)中登记。测试及原生运行不能代替真实云端、微信发送、真机和用户验收。

真实用户测试按审查报告第6节执行：10名目标用户做5秒理解、首次成稿、被打断接续、错误恢复和分享接收任务，分别记录完成率、耗时、失败动作、视觉评分、使用意愿及分享理由。8/10理解与完成等数值是验收目标，尚无实测用户结果。

传播先统计分享意图、独立接收打开、接收者首个服务端确认任务、D7有意义复用。没有发送曝光分母不报告真实打开率；打开/分享意图是代理量，不预测裂变收益。当前指标默认关闭，无新增线上遥测。
