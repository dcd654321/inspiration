# 待你提供

**这份清单是给「最后一起填」用的。** 开发过程中凡是卡在你这边的东西，都先留占位符继续往下做，不在这里逐条催。

三种类型，处理方式不同：

| 类型 | 含义 | 不给会怎样 |
| --- | --- | --- |
| **凭据** | 只有你能拿到的值（AppID、环境 ID、密钥） | 相关能力无法启用，其余照常 |
| **决策** | 需要你拍板的产品/技术选择 | 我先按保守默认做，可能返工 |
| **素材** | 设计资源、文案定稿 | 先用占位，界面能看但不完整 |
