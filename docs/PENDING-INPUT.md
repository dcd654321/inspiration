| --- | --- | --- |
| 备份与分享部署 | 指定环境核验 `linggan_` 集合、唯一索引、客户端全拒绝权限、函数部署版本及兼容策略 | 前五集合已创建；ai_usage、业务索引、规则、三函数尚未实施 |

| 照片 | `LINGGAN_PHOTOS_ENABLED=true`、当前环境准确的 `LINGGAN_STORAGE_PREFIX`、创建者私有存储权限及双账户读写/删除验证 | 客户端仅信任服务端能力；未核验之前不启用 |
| AI 模型 | 选择平台可用的模型标识、确认预算及云开发 AI 访问权限 | 客户端 `enabled:false`；服务端需 `LINGGAN_AI_ENABLED=true` 和 `LINGGAN_AI_MODEL` |

| 保留期清理 | 授权目标环境、备份、维护令牌、先演练核对计数，再授权执行 | 云端维护函数缺失；本地默认演练、无触发器；未删除真实数据 |
| 平台资料 | 小程序名称、类目、备案、隐私说明、相机/相册用途与公开分享内容规则 | 微信公众平台单独确认 |
| 平台验收 | 开发者工具受控云测试、iOS/Android 真机、两账户、弱网和多设备冲突 | 离线样例不能代替这些验收 |
